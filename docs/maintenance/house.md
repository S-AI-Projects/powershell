# house: isolated test runner

## File roles

| Path | Role |
|------|------|
| `exercises/practice/house/House.ps1` | learner stub, the `solution` file; must stay unsolved |
| `exercises/practice/house/House.tests.ps1` | Pester tests, the `test` file |
| `exercises/practice/house/.meta/House.example.ps1` | reference solution, the `example` file |
| `exercises/practice/house/.meta/config.json` | declares the three files above |
| `exercises/practice/house/.meta/tests.toml` | canonical case list, generated by `configlet sync` (see its header) |

Counts: 14 cases in `tests.toml`, none excluded; 14 `It` blocks in `House.tests.ps1`.

## Run

From the repository root, with PowerShell 7, Pester and Python 3:

~~~
python3 tools/course_checks/r09-t019.py
~~~

The runner reads `.meta/config.json`, copies the exercise (dotfiles included) into a temporary folder, replaces the solution file with the reference in that copy only, runs `Invoke-Pester -PassThru` there, prints `Executed cases: N`, and removes the temporary folder. The working tree is never written, so the learner stub stays unsolved. Options: `--exercise DIR`, `--filter PATTERN` (a Pester full-name filter), `--use-stub` (run the stub unchanged) and `--pause SECONDS` (wait before testing, for interruption tests).

| Exit code | Meaning |
|-----------|---------|
| 0 | tests ran and all passed |
| 1 | a test failed, or the PowerShell child failed or gave no result |
| 2 | no test was executed |
| 130 | the run was interrupted; the temporary copy is still removed |

## Empty selection

With a filter that matches nothing, Pester 6.2.0 still reports `TotalCount` 14 and result `Passed`; it only shows 14 tests as not run. A check of `TotalCount == 0` alone would therefore accept such a run. The runner counts the tests that were executed (passed plus failed) and exits with 2 when that number is zero.

## Checking the runner

`work/R09-T019/check.py` (coursework fork only, not part of any upstream change) runs the runner on the real reference (exit 0), on a deliberately failing copy of the reference (exit 1), on an empty selection (exit 2), on the unsolved stub (exit 1) and on an interrupted run (exit 130). Before and after every run it hashes all files of the exercise, and it confirms that no temporary folder is left behind.

~~~
python3 work/R09-T019/check.py
~~~
