# alphametics: isolated test runner

## File roles

| Path | Role |
|------|------|
| `exercises/practice/alphametics/Alphametics.ps1` | learner stub, the `solution` file; must stay unsolved |
| `exercises/practice/alphametics/Alphametics.tests.ps1` | Pester tests, the `test` file |
| `exercises/practice/alphametics/.meta/Alphametics.example.ps1` | reference solution, the `example` file |
| `exercises/practice/alphametics/.meta/config.json` | declares solution, test, and example files |
| `exercises/practice/alphametics/.meta/tests.toml` | canonical case list generated by `configlet sync` |

Counts: 10 test cases in `Alphametics.tests.ps1` (9 enabled, 1 skipped); 10 canonical cases in `tests.toml`.

## Run

From the repository root, with PowerShell 7, Pester, and Python 3:

```bash
python3 tools/course_checks/r09-t059.py
```

The runner reads `.meta/config.json`, copies the exercise (including dotfiles) into a temporary directory, replaces the solution file with the reference only in that copy, runs `Invoke-Pester -PassThru` there, prints `Executed cases: N`, and removes the temporary copy upon completion. The working tree is never written, ensuring the learner stub stays untouched.

Supported options:
- `--exercise DIR`: path to exercise directory (default: `exercises/practice/alphametics`)
- `--filter PATTERN`: a Pester FullNameFilter pattern to select specific tests
- `--use-stub`: run using the learner stub unchanged
- `--pause SECONDS`: wait before running tests (for interrupt testing)

### Exit codes

| Exit code | Meaning |
|-----------|---------|
| 0 | tests ran and all passed |
| 1 | a test failed, or the PowerShell process returned an error |
| 2 | zero tests executed (empty test selection) |
| 130 | process was interrupted (temporary copy still cleaned up) |

## Empty selection

With a filter matching no tests, Pester still reports a non-zero TotalCount and status `Passed` because it marks all non-matching tests as `NotRun`. Checking `TotalCount == 0` alone would accept an empty selection. The runner counts explicitly executed tests and exits with code 2 when `Executed == 0`.

## Checking the runner

`work/R09-T059/check.py` validates that:
1. Real reference exits 0 with 9 executed cases.
2. Deliberately failing reference exits 1.
3. Empty selection exits 2.
4. Learner stub exits 1.
5. All temporary directories are removed.
6. Learner files are hashed before and after all runs to verify they are never modified.

```bash
python3 work/R09-T059/check.py
```
